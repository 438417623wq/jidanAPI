# Issue #93：升级失败与版本状态修复

## 范围与假设

- 用户已确认按升级与回滚修复计划实施；面向插件内自更新用户。
- 修复代码中已复现的错误丢失、版本标识混淆、过早成功历史和备份安全问题。
- 不修改 Windows 属主、ACL 或 pnpm 状态；目录权限损坏的起因尚未确认。
- 继续使用固定公钥、签名清单和全部文件的摘要校验，不降低信任要求。
- 无运行依赖、无额外网络请求；备份时增加本地文件集合和摘要检查，工作量与包大小成正比。
- 恢复记录只包含升级阶段、版本与错误；不记录请求内容、密钥或用户会话。

## 决策与实现

### 一次升级同时覆盖安装和激活

Host 给 `PluginUpdater.apply()` 传入 `activate` 回调，由真实 `selfReload()` 确认激活结果。
只有文件验证及全部新 fiber 启动成功后，才记录成功历史并通知浏览器。
升级重载在替换旧实例前核对模块的目标版本；升级器提交成功记录前再次核对激活返回的版本。
缓存仍返回旧模块或缺少版本身份时不提交成功，进入回滚或未决恢复流程。
独立发布审计不提供回调，成功记录中的 `activated=false` 表示只验证安装。

相较于安装后另外修正历史，这样避免了一条短暂但可观察的假成功记录。
同一进程中的热重载前后使用共享锁；新实例读取持久历史和状态，不能并发覆盖安装。
升级通知通过新实例提供的回调发送，不访问已经销毁的旧实例设置存储。
热重载会断开 SSE，成功事件可能早于重连；客户端通过升级请求的成功响应结束本地升级阶段，
刷新状态并恢复按钮，不依赖成功事件必达。

### 运行身份与磁盘身份分开

Host 模块求值时捕获并导出 `version`，重新注册缓存中的旧模块时不再读新磁盘版本。
升级状态保留 `current` 字段表示运行版本，并新增 `runningVersion`、`installedVersion`、
`versionMismatch`、`recoveryRequired` 和 `phase`。

面板展示两个版本；版本不同或存在未决恢复时不显示“已是最新版本”。
版本相同不能证明文件完整，已知不完整事务也会显示恢复警告。
无法导入插件的冷启动，仍需在应用外恢复；面板不能修复一个根本没有启动的模块。

### 备份与恢复

先在独立临时目录制作备份，校验文件集合及大小、摘要，再替换保留的 `rollback` 副本。
备份失败时不覆盖已有可用备份、不修改安装文件。
新备份带隐藏的 `.ofm-backup.json` 校验记录；旧版本无记录的备份仍可使用，
但只能确认其现有文件，不能证明历史上是否少了其他文件。

恢复前校验备份，先复制旧文件，再清理旧版没有的文件；复制和清理失败都必须报告。
恢复后再校验文件集合与摘要。原始失败和回滚失败同时保留，不能把磁盘恢复说成运行模块恢复。
普通手动重载和源码监听重载不触碰升级备份，避免覆盖开发修改。

### 中断与恢复门禁

覆盖文件前写入 `upgrade-state.json`，记录 `installing` / `activating` 意图。
完成后为 `complete`；回滚成功为 `rolled-back`；恢复不完整为 `recovery-required`。
没有进程内活动事务的未完成意图视为中断，不永远展示“升级中”。

未决恢复时禁止再次安装和重载，并保留备份位置。
手工恢复并重启后，检查更新会核对当前磁盘与备份的全部字节及旧运行版本；
只有匹配时才解除恢复门禁。无法访问目录或备份损坏时不会自动解除。

## 验证设计

- `scripts/updater-test.mjs`：签名夹具及真实 `selfReload()`，覆盖导入失败、
  新 fiber 启动失败、旧运行恢复失败、正常激活、安装与回滚拒绝、损坏备份、
  备份失败、清理失败，以及中断状态与手工恢复。
  同时覆盖 Host 缓存返回旧模块、激活回调返回旧版本或缺少版本的拒绝。
- `scripts/upgrade-ui-test.mjs`：真实客户端组件和隔离 Host 副本，覆盖双版本显示、
  同版本不完整安装、成功指示门禁、无 SSE 时成功及失败响应释放按钮、
  旧模块身份及普通重载不覆盖磁盘。
- 故障注入验证代码分支；不等于 Windows 原生 ACL、杀毒软件锁或真实桌面 HMR 验收。

## 交付与回退

修改了签名发布集合，维护者发布前必须重签清单并按发布规范更新目录记录。
贡献者离线测试使用一次性测试密钥，不需要发布私钥。
本修复不会修好此前已损坏的 Windows 目录权限。

回退代码时关闭应用并恢复上一份已验证安装。旧版不认识新的事务状态，
因此应先完成已有恢复，保留备份后再降级，避免旧版绕过恢复门禁继续覆盖。
